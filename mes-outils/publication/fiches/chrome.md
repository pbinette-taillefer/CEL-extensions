# Fiche Chrome

## Paragraphe de démarrage à ajouter

Nécessite Chrome 138 ou ultérieur sur ordinateur. Dans les détails de Mes outils sur la page des extensions, activez « Autoriser les scripts utilisateur », puis revenez dans Mes outils pour ajouter votre premier outil.
